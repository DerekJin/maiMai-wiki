# 睡眠与作息

## 11月龄睡眠需求

- **总睡眠**：12-15小时/天
- **夜奶**：可能还需要1-2次
- **作息规律**：固定时间、固定流程

| 时间 | 内容 |
|------|------|
| 07:00 | 起床、换尿布、洗漱 |

| 08:00 | 早餐 |
| 09:30 | 户外活动 |
| 11:30 | 午餐 |
| 12:30 | 午睡（1.5-2小时） |
| 15:30 | 点心 |
| 16:00 | 户外/室内活动 |
| 18:30 | 晚餐 |
| 19:30 | 睡前奶（200ml） |
