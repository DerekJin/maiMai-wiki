# 大动作发展

## 11月龄里程碑（Mayo Clinic）

- 可以独自坐着
- 能自行站起来
- 扶着家具侧移
- 走得早的能牵手走几步

## 站立训练进阶

| 月龄 | 目标 |
|------|------|
| 8月 | 扶着慢慢学站 |
| 9月 | 自己扶着家具站 |
| 10月 | 引导站立（玩具放高处吸引扶站） |
| 10-11月 | 牵手练习迈步 |

## 每日大运动建议

- **站立练习**：每天3-5次，每次5-10分钟
- **爬行**：继续强化（为走路打基础）
- **户外活动**：1-2小时/天

## 精细动作
- 堆叠积木（2cm大小）
- 捏取小物品
- 放入/取出容器
- 拉绳子玩具
